Layer:01

PRESENT DAY

Why it exists

  1. It was never real. In Serial Experiments Lain, Copland OS Enterprise is the system on the NAVI computers, made by Tachibana General Laboratories. It existed only on screen. This is a working one you can install. (lain.wiki)
  2. A whole system, not a theme. One look from the moment the computer starts: boot menu, boot animation, login screen, desktop, terminal, even the text console. The ISO carries all of it.
  3. Nothing random. Every colour, font and setting was chosen for a reason, and the reasons are written down in DESIGN.md.
  4. Plain Debian underneath. Debian's own packages and security updates, plus one package for the Copland look. Both update with the same command. The base is named everywhere; nothing is hidden.
  5. Free, for people who love the show. A non-commercial fan project, made for fun. No account, no ads, no cost.

Layer:02

NAVI

What you get

The desktop

  • Copland OS menu, top left. All your apps and a search box; the Windows key opens it.
  • Desktop icons, left, in the style of Mac OS 9 (NineIcons). The mouse pointer is a classic Mac arrow in pixel art (Retrosmart).
  • Layer:01 to Layer:04, top right. The show calls its episodes Layers; here they are your four desktops. Windows+1 to 4 switches layer, Windows+Shift+1 to 4 sends the current window there, and the Layers app sets which app opens on which layer. The current layer is underlined in cyan.
  • Network, volume, clock and power, at the right end of the bar. Names on the bar are set in C059 Bold Italic, the Copland font for names.
  • The Copland OS Enterprise image as wallpaper. The colours of the whole system, from the bar to the terminal, are taken from it: navy, cyan and pale blue.

At work

  • Open windows of the current layer only, in the bar next to the menu.
  • Window titles, centred at the top of each window, in C059 Bold Italic. Everything you read inside windows is in Nimbus Sans.
  • The system summary every new terminal opens with (top left), next to the eye drawn in text. Its labels use the show's words: NAVI is your computer (the show's name for a personal computer), PROTOCOL the Linux kernel (Protocol 7 is the show's network protocol), PSYCHE the processor (the Psyche chip Lain adds to her NAVI), and WIRED your network address (the Wired is the show's network).
  • Sixteen terminal colours (bottom left) in the Copland palette. Errors still read red, success green, warnings yellow, in softer tones. The terminal font is DejaVu Sans Mono.
  • btop (right), the system monitor, in the same colours.

From the moment it starts

  • Boot menu named Copland OS Enterprise, in the Copland colours, at your screen's resolution.
  • Boot animation: the eye, full screen, while the system starts.
  • Login screen in the same theme, the box centred over the eye.
  • Text console: even it greets you with Copland OS Enterprise (Debian 13).

Pictures of these come with the first release.

Apps

  • Firefox ESR for the web
  • Thunar for files
  • Mousepad for text
  • Ristretto for images
  • Atril for PDFs
  • Xarchiver for archives
  • Screenshooter for screenshots
  • Volume control for sound
  • Network manager for Wi-Fi and wired networks
  • btop to see what the computer is doing
  • Install Copland OS (Calamares) to install it

Debian keeps every one of them up to date, with the rest of the system.

Layer:03

PROTOCOL

What it's for

An everyday computer

Browse, write, read PDFs, look at photos, listen, connect to Wi-Fi: the apps above do it from the first start. Underneath is Debian 13 "trixie", released on 9 August 2025 with 69,830 packages at the time, and every one of them installs with one command. For example LibreOffice, GIMP, VLC, OBS Studio, Flatpak, and Steam (from Debian's contrib section). (Debian, packages.debian.org)

sudo apt install libreoffice gimp vlc

Why X11

Copland OS runs the XFCE desktop on X11, the display system Linux desktops have used for decades, on purpose:

  • XFCE's window manager works only on X11; XFCE's Wayland support is still experimental in 4.20 (the version in Debian 13), and XFCE keeps X11 "for the foreseeable future". (XFCE roadmap)
  • The layer rules (which app opens where) use devilspie2, an X11 tool. (packages.debian.org)

There is no Wayland session. That is a choice, not something missing by accident.

Updates

Debian's security updates and Copland's own updates arrive the same way. Debian 13 is supported until 9 August 2028, and with long-term support until 30 June 2030. (Debian)

sudo apt update && sudo apt upgrade

Layer:04

PSYCHE

What it runs on

The same as Debian 13, so old PCs are welcome: Debian needs only the plain 64-bit instruction set (x86-64) that PCs have had since 2003, nothing newer. (Debian wiki, x86-64)

Processor
Any 64-bit PC (x86-64). Not 32-bit: Debian 13 has no 32-bit installer.
Memory
1 GB minimum, 2 GB recommended.
Disk
10 GB.
Starts on
UEFI and older BIOS PCs.
USB stick
2 GB or more.

Memory and disk are Debian 13's own figures for a desktop install (Debian installation guide). The Copland desktop itself uses about 300 MB of memory, measured on a Dell Vostro 3671 (Intel Core i3-9100, 4 GB).

Layer:05

WIRED

Get it

Download CoplandOS.iso

Free. Every release is on GitHub.

  1. Download CoplandOS.iso with the button above (it always gives the newest release).
  2. Put it on a USB stick with a free tool such as balenaEtcher (Windows, macOS, Linux). This erases the stick.
  3. Start your PC from the stick. Plug it in, restart, and press your PC's boot menu key while it starts (often F12, F11 or Esc), then choose the USB stick.
  4. Try it. Copland OS runs straight from the stick. Nothing on your computer changes.
  5. Install it when you are ready: open Install Copland OS and follow the steps.

Already on Debian?

With Debian and XFCE already installed, you can get the Copland look without reinstalling: the steps are on GitHub.
