Copland OS Enterprise

Produced by Tachibana General Laboratories · Present day, present time

The operating system from Serial Experiments Lain, as a real computer you can use every day. Put it on a USB stick, try it without installing anything, and install it when you like it.

Download CoplandOS.iso How to install

The first release is not out yet. It will be downloadable here, free, for 64-bit PCs.

Layer:01Try it, then install it

  1. Download CoplandOS.iso from this page.
  2. Put it on a USB stick with a free tool such as balenaEtcher (Windows, macOS, Linux). This erases the stick.
  3. Start your PC from the stick. Plug it in, restart, and press your PC's boot menu key while it starts (often F12, F11 or Esc), then choose the USB stick.
  4. Try it. Copland OS starts straight from the stick. Nothing on your computer changes.
  5. Install it when you are ready: open Install Copland OS and follow the steps.

Layer:02What you get

The look from the show

Navy and cyan from Copland OS's boot screen, the eye, classic Mac icons and cursors.

Four layers

Four desktops, Layer:01 to Layer:04. Press Windows+1 to 4 to switch, and choose which app opens on which layer.

Ready to use

Firefox, files, a text editor, image and PDF viewers, sound and Wi-Fi settings.

From power on

The Copland look from the boot menu and start-up animation to the login screen.

Built on Debian

Underneath is Debian 13, one of the oldest and most trusted free operating systems.

Free

No account, no ads, no cost. A fan project, made for fun.

Layer:03Updates

Copland OS gets Debian's security updates and its own updates the same way. To update, open the terminal and run:

sudo apt update && sudo apt upgrade

Layer:04Already on Debian?

If you already use Debian with the XFCE desktop, you can get the Copland look without reinstalling. The steps are on GitHub.
